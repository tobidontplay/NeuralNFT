# Project Brief: NeuralNFT

## Vision
A visitor generates art, browses a gallery, and mints. The contract is server/contracts/NeuralNFT.sol. Which Express entry is canonical is not decided here.

## Target User
A visitor with a wallet, and a developer running the client. Deployment network was not confirmed in this pass.

## Success Criteria
- [ ] The client pages render: home, create, gallery, my NFTs.
- [ ] One Express entry is chosen and the other is marked unused.
- [ ] The contract address, if deployed, is written down from a real deploy output.

## Out of Scope
- A claim that the contract is on mainnet. Not verified here.
- A test command.
