# Prompt Patterns (Meta)
## XML Sandwich
**When:** complex instructions with multiple concerns.
**Example:**
<context>...</context>
<task>...</task>
<constraints>...</constraints>
## Perfection Loop
**When:** first answer isn't good enough.
**How:** ask for critique, then refactor.
## Decomposition
**When:** task too big for one prompt.
**How:** plan first, then implement step by step.
## Role Anchoring
**When:** need consistent voice or standards.
**How:** assign a persona (see agent-rules.md).
