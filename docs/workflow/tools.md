# Tool Routing — Which Tool For Which Job
| Job | Tool | Why |
|-----|------|-----|
| Interactive coding, refactors | Cursor Pro | Best inline context, plan mode |
| Large autonomous tasks | Codex Plus | Cloud sandbox, PR output |
| Cost-sensitive bulk work | Claude Code + DeepSeek | Cheapest capable option |
| Long-form reasoning / planning | Claude Code | Strong at architecture |
| Quick lookups | ChatGPT | Free tier |
## Cost rules
- Primary sessions → DeepSeek Pro; sub-agents → DeepSeek Flash.
- Log any call over $0.05 in cost-log.md.
- Weekly total at the bottom of each week.
