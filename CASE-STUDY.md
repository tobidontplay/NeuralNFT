# Case Study: NeuralNFT
## Problem
An AI art mint needs a page, an API, and a contract, and this repo grew all three without a single start path.
## Approach
Leave both servers in place. Point project.yaml at the root dev script. Record the port fallback without using it as the repo port.
## Result
The client pages, both servers, and the contract file are documented. Nothing was deleted. No tests. Last product commit on main is the 2025-05-03 rename.
## What I'd do differently
I would have deleted one server before the second one was written, and I would have committed the deploy address next to the contract.
## Metrics
- Time to first working version: Two commits on main. Last 2025-05-03.
- Total AI spend: Not recorded.
- Features shipped: Client UI is in the tree. The mint path is in progress until one server and a deploy are confirmed.
